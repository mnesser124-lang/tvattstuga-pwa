Tvättstuga PWA – نسخة اختبار GitHub Pages فقط
الإصدار: V25 TEST ONLY

هذه الحزمة مهيأة للنشر التجريبي من جذر المستودع عبر GitHub Pages.
المحتويات: index.html وملفات CSS/JavaScript وservice worker وmanifest والأيقونات.

تحذير مهم:
- للاختبار ببيانات وهمية فقط، وليست للاستخدام الحقيقي.
- لا تُدخل أسماء أو أرقام غرف أو بيانات سكان حقيقية.
- لا ترفع بيانات السكان أو رموز PIN أو نسخًا احتياطية إلى GitHub.
- لا توجد PIN افتراضية مضمّنة في الشيفرة؛ عند أول محاولة دخول تُنشأ PIN تجريبية محليًا في المتصفح.
- تسجيل الدخول داخل تطبيق ويب ثابت ليس حماية أمنية مناسبة للبيانات الحساسة.
- التخزين في المتصفح محلي لكل جهاز/متصفح، ولا يوفّر مزامنة أو نسخًا احتياطيًا مضمونًا.
- اختبارات Node السابقة نجحت للسياسات المحددة، لكنها لا تثبت عمل التطبيق على Samsung فعليًا.

النشر: يجب أن تكون index.html في جذر الفرع الذي يختاره GitHub Pages، لا داخل مجلد فرعي.
